# 0.2.2

A small update that makes the book sturdier.

## English

**Fixes**
- When the game could not find one of the diary's icons, drawing a day page could stop halfway. The page now falls back to the book icon and is drawn in full.

## Deutsch

**Fehlerbehebungen**
- Fand das Spiel eines der Symbole des Tagebuchs nicht, konnte eine Tagesseite mittendrin aufhören. Die Seite nimmt jetzt ersatzweise das Buchsymbol und wird vollständig gezeichnet.
